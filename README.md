# Daymark Task List

A small browser-only To-Do application built with HTML, CSS, and JavaScript.

## Run

Open `index.html` in a current browser. No installation, build step, backend, or database is required.

## Add Tasks

Enter a task description and select **Add**, or submit the form with Enter. New tasks appear in the list immediately. Empty and whitespace-only descriptions are rejected; surrounding whitespace is removed from accepted descriptions.

Tasks are kept in memory for the current page session. Refreshing the page clears the list.
